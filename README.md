# Plant Care System

## Название проекта

**Plant Care System — система ухода за растениями**

## Назначение

Приложение помогает пользователю следить за домашними растениями и вовремя ухаживать за ними. В нем можно хранить информацию о растениях, отмечать выполненный уход и получать напоминания.

## Целевая аудитория

Приложение предназначено для людей, которые выращивают растения дома, в офисе или на даче.

## Предметная область

Предметная область проекта — уход за растениями. Сюда входят полив, удобрение, пересадка и другие действия, необходимые для роста растений.

## Основные сущности

- Пользователь
- Растение
- Вид растения
- Уход за растением
- Напоминание
- Запись о выполненном уходе

## Основные функции полного приложения

- Регистрация и вход пользователя
- Добавление растений
- Просмотр списка растений
- Изменение информации о растении
- Удаление растений
- Добавление фотографии растения
- Создание напоминаний о поливе
- Создание напоминаний об удобрении и пересадке
- Отметка выполненного ухода
- Просмотр истории ухода за растением

## Что работает на ПР1

Программа написана на Python. Пока она работает в консоли с одним растением.
Реализованы три функции:

- Расчет даты следующего полива — get_next_watering.
- Проверка, пора ли поливать растение — get_watering_status.
- Отметка выполненного полива — mark_watering.

Программа показывает данные фикуса и спрашивает, выполнен ли полив.
При ответе «да» дата полива меняется на сегодняшнюю и рассчитывается новая дата.
При ответе «нет» данные не меняются. Другой ответ выводит сообщение об ошибке.
Данные хранятся только во время запуска и не сохраняются после закрытия.
Интервал в семь дней задан для учебного примера, а не как совет по уходу.

Использованы строки, целые числа, логическое значение, преобразование int,
операции с датами, условия, функции и импорт из datetime.
Классов, циклов и базы данных пока нет.

## Запуск на Windows

Установите Python 3 и Git. Откройте командную строку и выполните:

```bat
git clone https://github.com/Hehekutov/PlantCareSystem.git
cd PlantCareSystem
py -m venv .venv
.venv\Scripts\python main.py
```

Если проект уже скачан, откройте его папку и выполните git pull.
Для программы не нужны дополнительные библиотеки.
В VS Code выберите Python из .venv как интерпретатор проекта.

## Проверки

```bat
.venv\Scripts\python -m pip install pytest
.venv\Scripts\python -m pytest -q
```

Проверяются дата полива, три варианта напоминания и отметка полива.
